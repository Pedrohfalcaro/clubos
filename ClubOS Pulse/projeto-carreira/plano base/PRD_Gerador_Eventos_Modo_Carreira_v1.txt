PRD — Gerador de Eventos para Modo Carreira

Versão: 1.0

1. Visão Geral

O objetivo é desenvolver uma aplicação web offline (HTML, CSS e
JavaScript puro) que funcione apenas abrindo o arquivo index.html.

A aplicação atua como um gerador narrativo para modos carreira de jogos
de futebol, criando acontecimentos antes das partidas para tornar cada
temporada única.

Não há integração com EA FC ou FIFA. O usuário apenas registra seu
elenco e consulta o sistema antes de cada jogo.

------------------------------------------------------------------------

7. Sistema de Probabilidades

Chance padrão: Nada = 72% Evento = 28%

Categorias: Atleta = 30 Diretoria = 15 Torcida = 15 Imprensa = 12 Lesão
= 10 Financeiro = 6 Família = 5 Transferência = 4 Patrocínio = 2
Escândalo = 1

Cada categoria possui: Comum Incomum Raro Muito raro

muitas vezes seguidas
